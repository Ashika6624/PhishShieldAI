# 🛡️ PhishShieldAI

An AI-powered phishing email detection system using Machine Learning.

## 📌 Project Overview

PhishShieldAI is a machine learning application that detects whether an email or SMS message is **Phishing/Spam** or **Legitimate (Ham)**. The project uses Natural Language Processing (NLP), TF-IDF Vectorization, and a Multinomial Naive Bayes classifier to classify messages with high accuracy.

---

## 🚀 Features

- Detects phishing/spam emails and SMS
- Machine Learning based classification
- TF-IDF text vectorization
- Streamlit web application
- Interactive dashboard
- Fast prediction with trained model
